# blog.nozomi.space

Hugo + [PaperMod](https://github.com/adityatelange/hugo-PaperMod). Deployed to GitHub Pages by `.github/workflows/hugo.yaml` on push to `main`.

    git clone --recurse-submodules git@github.com:mkopec/blog.nozomi.space.git
    hugo server -D                     # local preview
    hugo new content posts/my-post.md  # new post
